# 多一小步手機 App

在同一個 Site 上提供 PWA；沿用 R2 `BUCKET`、`small-step/v1/` 資料版本及既有管理員帳號，不建立第二套資料或後台。

- `/manifest.webmanifest`：繁體中文名稱、獨立視窗、主畫面與 maskable 圖示。
- `/sw.js`：根目錄範圍。建置時依資產雜湊產生版本；更新需使用者點選，避免閱讀中重載。
- `/offline.html`：中斷連線的中性提示。只快取離線頁與圖示；不快取統計、員工名單、便條紙、後台頁面、API 或登入資訊。
- `/pwa.js`、`/pwa.css`：安裝說明、連線與版本提示、五個手機導覽入口、安全區域間距。
- 下方全部便條紙增加獨立年份篩選；仍每頁十則，上方暖心精選仍四則／六秒。
- 員工名單下載範本順序：部門、組別、姓名、到職日、離職日。上傳仍相容舊版部門、姓名、組別順序，按標題判別後轉為相同物件結構。

## 安裝

Android／三星：用 Chrome 或 Samsung Internet 開啟正式網址，點「安裝 App」。若沒有瀏覽器原生提示，從瀏覽器選單選擇安裝應用程式／加入主畫面。

iPhone／iPad：用 Safari 開啟正式網址，分享 → 加入主畫面 → 加入；新版系統如顯示「作為網頁 App 打開」，保持開啟。

PWA 不包含商店上架套件，統計與後台需要網路。資料上傳後，各裝置重新整理即取得同一版本。

## 驗證

執行 `npm run build`、`npm test`。PWA 測試涵蓋 manifest MIME、圖示實際尺寸、SW 更新版本與快取範圍、離線導航，以及新舊名單欄位相容。

實機安裝驗收：Android 與 iOS 加入主畫面後，確認圖示、獨立視窗、螢幕安全區、Excel 檔案選擇及離線提示。開發環境的窄版瀏覽器驗證無法取代作業系統安裝驗收。
