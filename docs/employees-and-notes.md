# 員工登入與網站便條紙

前台順序為便條紙、寫便條紙、數據總覽、部門分析、個人票數、個人設定；登入後預設進入便條紙。主管署名移至後台獨立頁籤，沿用年／季／月／部門篩選及排名配色。

## 帳號啟用

由後台管理員在「員工帳號」選擇員工名單 Excel，讀取 C 欄姓名、F 欄工號、G 欄初始密碼，預覽姓名與工號後確認匯入。未填 F/G 的列略過，僅填一欄則阻擋。此操作不修改名冊日期、票數或既有後台帳號。姓名必須存在網站名冊；離職及未到職者不能登入。

工號保留前導零。初始密碼至少 4 個字元；員工在個人設定修改時至少 8 個字元。工號及姓名由人資維護，個人設定只允許修改自己的密碼。重新匯入預設保留既有密碼，管理員明確勾選重設才覆寫。密碼採各自隨機 salt 與 PBKDF2 SHA-256；不儲存或提供明文密碼，登入 Excel 不保留原始檔。若一般資料匯入檔含密碼，介面會指引改用員工帳號匯入。

員工使用獨立 HttpOnly／SameSite=Strict cookie，HTTPS 時 Secure，登入期限 8 小時。每次請求重新驗證帳號版本、名冊狀態；修改或重設密碼使舊登入失效。員工 cookie 無法使用任何後台 API，包含下載與主管統計。

使用者已提供温欣美的工號與初始密碼，員工名單已更新這一筆。部署設定 EMPLOYEE_BOOTSTRAP_ACCOUNT 保存此筆帳號的 salt 與 hash，首次使用時寫入 R2，已存在的工號或姓名不會重設。其餘名單 F/G 仍空白，待填妥後匯入。既有後台登入不受影響。

## 填寫與統計

欄位參考使用者提供的 Microsoft Forms：
https://forms.office.com/r/RxrPajR6Wt?origin=lprLink

填表人由登入身分自動帶入；幫忙的人以姓名文字輸入並提供在職名單提示，方式與被幫忙的人相同；被幫忙的人填全名；後兩者皆提供「同填表人」。事件說明可留白，維持原始紀錄的計票規則。日期、月份、年度由伺服器依臺灣時間產生。目前管理 2026 年，新年度需先擴充統計模型再開放填寫。

便條紙寫入本站，未送到 Microsoft Forms。每張增加電子基礎票 1 票，填表人署名 1 筆，不自動加分或加入暖心精選。幫忙的人與填表人相同時仍各計一次。前台更新電子便條紙與統計。提交識別碼用於避免重送；同一識別碼不同內容會拒絕。所有文字顯示前經 HTML escaping。

網站便條紙與 Excel 基礎統計分開保留，讀取時合併，不改變目前 R2 統計版本指標。上傳 Excel 或還原不刪除網站紀錄。後台「網站便條紙」可查閱與下載；下載檔已計票，請勿重複匯入。備份 JSON 包含 webSubmissions，可保留此獨立紀錄。歷史統計備份仍維持其基礎快照，webSubmissions 為下載當時的網站紀錄。

儲存位置均沿用現有 R2 BUCKET：small-step/employees/v1/ 下的 users.json、sessions、attempts、notes.json，與既有統計與後台帳號分開。帳號與網站便條紙使用條件寫入避免併發覆蓋。

## 驗證

建置後執行 node --test tests/*.test.mjs。employees.test.mjs 涵蓋員工驗證、帳號匯入、前導零、密碼重設、在職狀態、權限隔離、來源檢查、便條紙去重與統計計算。僅使用記憶體與本機測試資料，不寫入正式 R2。

暖心精選與全部電子便條紙集中在「便條紙」頁籤，填寫卡牌獨立在「寫便條紙」頁籤。手機填寫時隱藏分析篩選與重複頁面標題，採緊湊單欄表單；短螢幕、鍵盤開啟或展開指南時保留自然捲動。

## 最新名單同步與停用規則

2026/11/17 新版名單含完整到離職日期。管理員在「員工帳號」匯入時先預覽，再一次同步員工資料與登入帳號。密碼空白（含全空格）一律停用，撤銷舊密碼與登入；沒有工號則依姓名停用既有帳號。離職生效日當天與未到職者不可登入。仍有填密碼的既有在職帳號預設保留員工自行修改後的密碼；明確勾選重設才替換。

帳號與名冊使用同一個 R2 CURRENT 條件指標切換。CURRENT 的 employeeDirectoryKey 指向不含明文密碼的不可變帳號目錄；既有單一 users.json 只用於相容讀取。密碼修改或帳號停用同樣建立新目錄並條件更新 CURRENT，避免並行更新互相覆寫。上傳統計及還原保留最新帳號目錄，不會恢復舊密碼或已停用的登入資格。完整目錄同步另保留名單提供的到離職依據，避免還原歷史統計時重新啟用離職人員。

/api/admin/directory-sync 平常只允許管理員。受信任的發布維護流程可暫時設定 DIRECTORY_IMPORT_KEY，使用相符的 x-small-step-directory-key 做一次同步；完成後移除此設定並重新部署，維護通道即失效。此設定不會傳至瀏覽器。

首頁 / 與 /index.html（含查詢參數及 HEAD）在伺服器驗證員工登入；資料 API 另外獨立驗證。未登入回登入頁，無法讀取統計或便條紙。從瀏覽器上一頁快取回復時，先隱藏舊畫面再驗證；重新切回分頁也重新檢查登入狀態。離線快取仍只保留中性提示與圖示。
